# Pine Hill Test experimental route package attribution

This package is an experimental reconstruction. It must remain explicitly labelled experimental in any distribution.

- Route geometry and mapped features: © OpenStreetMap contributors, ODbL 1.0.
- Elevation terrain: AAM NZ and Otago Regional Council, Otago Dunedin and Mosgiel LiDAR DEM (2021), supplied through Toitū Te Whenua Land Information New Zealand, CC BY 4.0.
- Mature broadleaf tree source asset: Rico Cilliers / Poly Haven, Tree Small 02, CC0 1.0. The Wodra runtime mesh is a reduced derivative.
- Wodra-authored intersection geometry and scene assembly: Wodra, 2026.
- Fence texture: cropped from the route owner's video captured 3 November 2026, then rectified for a fence mesh. No raw video, GPS original, vehicle plate, person, or unredacted frame is included in this package.

The fence texture is owner-supplied footage, not a separately licensed public asset. Obtain owner approval before public distribution. The package's `runtime-assets` folder is an audit/install payload; the matching assets must also be included in the Wodra application PCK for `res://` references to resolve.
