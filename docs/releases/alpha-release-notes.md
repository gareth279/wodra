# Wodra alpha release

This is a Windows x64 public alpha build. See the commit list included by the release workflow for changes in this version.

## Before riding

- Confirm your trainer is discovered and shows Ready before starting a real trainer ride.
- Use a dummy trainer to explore without hardware.
- Back up important FIT files as you would with any alpha software.

## Known limitations

- Trainer connection changes remain under hardware verification for Tacx Flux 2 (issue #1).
- Windows downloads are currently unsigned. The installer and executable may show SmartScreen warnings until the signing plan in issue #15 is completed.
