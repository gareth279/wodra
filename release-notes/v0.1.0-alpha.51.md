# Wodra v0.1.0-alpha.51

## Changes

- Fixed the trainer recovery Retry button signal lifecycle. Repeated disconnect, searching, and retry transitions now invoke only the current action.
- Added explicit numeric x/y/z coordinates to ambient actor spawn and path-endpoint diagnostics.
- Ambient cars now follow cyclists ahead on the same road path, keep clearance from local, AI, ghost, and interpolated remote riders, and yield before close pedestrian path conflicts.

## Verification

- Windows Debug and Release solution builds and automated regression suites passed.
- Godot 4.6.2 production RideScreen recovery/diagnostic checks and deterministic ambient traffic scene checks passed.
- Automatic trainer, heart-rate, and steering discovery remains subject to owner physical acceptance testing with Windows Bluetooth/ANT+ hardware. No physical hardware results are claimed by this release.
