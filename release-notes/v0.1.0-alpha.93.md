# Wodra v0.1.0-alpha.93

## Changes
- **Pine Hill Test is now a repeatable 1,322.354-metre road loop**, reconstructed from the existing Alpha.92 GPS geometry, with the spurious short backtracking spur removed.
- Ride recording, lap tracking and progression continue across multiple laps instead of ending automatically after one traversal.
- Experimental scenery improvements: route-wide residential building styles and facade details; estimated roadside planting, hedges, fencing and utilities linked to source-video checkpoints. The authored give-way intersection remains.
- Release verifier accepts the opt-in seven-route package and `routeId` scene sidecars. The six normal routes remain included.
- Original video files and raw unredacted frame captures are not part of the release.

## Validation
- On PR #177, Debug and Release checks and CodeQL passed.
- Godot 4.6.2 production RideScreen simulated-trainer test reported three continuous lap boundaries, an active FIT recording, and normal manual session completion. Final FIT recorded 3,978.7 metres.
- A deterministic geometry report confirms an exactly closed seam with continuous tangent/elevation.
- Local publisher regression passed the six-route default and opt-in seven-route package. The final Alpha.93 publisher build, package integrity and installed/exported-app smoke tests must still pass before public release.

## Known limitations
- **Pine Hill scenery is experimental, not video-faithful.** Most individual residential building styles are neighbourhood-level estimates. Some parked vehicles, kerbs, gardens and distinctive streetscape elements remain absent or simplified.
- Physical trainer ride and end-to-end user installation remain useful follow-up checks. This release is for hands-on validation of the corrected loop and scenery, not an assertion of final visual acceptance.
- Other existing rider/garment visual work remains separate.

## Installation
- Windows installer, portable ZIP, Velopack full update package and Alpha update feed are published using the normal signed-off Wodra alpha publisher.
- Preserve existing rider profile data and normal Alpha channel behaviour.
