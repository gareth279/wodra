# Wodra 0.1.0-alpha.80

## Improved

- Add compact Ride, Route and Riders screens to Wodra Companion, using the existing trusted read-only phone connection.
- Show a route overview and elevation profile from the active route geometry, with live rider position, progress, lap, distance and gradients.
- Show nearby AI and multiplayer riders with privacy-limited display names and lap-aware relative distances.
- Keep static route data cached by version and transfer only compact live ride and rider state during polling.

## Validation

- Windows Debug and Release builds, production Godot scene tests, and companion API checks on PHP 8.2 and PHP 8.5 passed in CI.
- Companion app and Wake Lock browser tests passed; responsive captures covered compact and standard phone sizes and landscape.
- Website changes are supplied as a public-files-only deployment bundle; no production website files or private configuration are included.
