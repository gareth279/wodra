# Wodra 0.1.0-alpha.71

## Added

- Add Wodra XC Skills Loop, a fictional 1.6 km closed MTB course with 26 m of authored course ascent, rollable centerline bypasses, and three optional jump lines.
- Add route-authored singletrack features, visual-only airtime, optional Gaming score, and lap summaries without changing cycling distance, climbing, trainer resistance, or timed personal bests.
- Disable ambient cars and pedestrians on the MTB XC course while preserving existing road traffic and support for other environments.

## Validation

- Dummy-driven production rides exercised the Big Easy MTB route and XC course, including bypasses, jump lines, pause/resume, recording, and road/gravel/velodrome environment transitions.
- Debug and Release builds, regression suites, isolated packaged startup, and extracted XC route-asset smoke checks passed.
- The course is fictional and uses no surveyed geography. Owner visual acceptance, physical trainer, and Sterzo acceptance remain pending.
- This release delivers the bounded XC loop MVP; broader issue #69 phases remain open.
