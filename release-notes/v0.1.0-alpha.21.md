# Wodra v0.1.0-alpha.21

- Adds optional ANT+ Setup in the startup screen. Riders can configure Garmin's standard ANT+ network key once per Windows account; Wodra stores it locally outside the installation and retains it through updates.
- Removes ANT+ key material from public source resources and the release build pipeline.
- Keeps the alpha.20 FE-C receive callback and frame parsing fixes.
- Preserves Bluetooth FTMS behavior. Real Flux 2 discovery, control and recovery still need owner hardware acceptance.
