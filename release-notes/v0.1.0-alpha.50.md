# Wodra v0.1.0-alpha.50

This release is for Windows physical testing of automatic trainer and optional device discovery.

- First Connect independently discovers and connects an eligible Bluetooth FTMS trainer, heart-rate monitor, and Elite Sterzo Smart.
- One matching device connects automatically; multiple matching devices get a picker. Saved Bluetooth identities are preferred.
- Optional heart-rate and steering discovery do not block trainer readiness. Scans can be cancelled, and retry/reconnect paths have automated coverage.

## Physical acceptance still required

Issue #6 remains open until testing with real Windows hardware confirms Tacx Flux 2, heart-rate, and Sterzo Smart automatic connection; simultaneous operation and correct power, cadence, heart-rate, steering and FIT/Strava recording; unavailable optional devices; reconnect across launches; disconnect/retry/cancel behavior; and ANT+ FE-C when selected.

Automated Windows Debug and Release validation passed on the final PR commit, including regression suites and the production RideScreen fake-device test. This does not substitute for hardware acceptance.
