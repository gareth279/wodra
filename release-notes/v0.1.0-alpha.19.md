# Wodra v0.1.0-alpha.19

## ANT+ diagnostic update

- Records ANT SDK dependency availability, USB enumeration count, device open/release, embedded configuration load status, ANT command IDs and results, response/event codes, FE-C page numbers, elapsed times, trainer identity, and readiness state. Network-key bytes and raw ANT payloads are never logged.
- Retries the FE-C capabilities-page request up to three times when the page is not received; readiness still requires trainer telemetry and capabilities.
- Adds `tools/ant-sdk/Probe-AntUsb.ps1` for read-only SDK enumeration and open/release checks. The probe does not configure a key, open a radio channel, send trainer data, or issue resistance commands.
- Updates the ANT+ setup hint; the embedded release configuration remains in use. Bluetooth FTMS behavior is unchanged.

## Current verification status

- Alpha.18 logs show the ANT SDK USB enumeration call returned zero devices on the `C:\Users\bike` runtime. The connection attempt stopped before network assignment or FE-C discovery.
- Garmin's ANTUSB-m component documentation lists scanning mode support. This release does not change scan mode or claim the hardware connection is fixed.
- Flux 2 ANT+ discovery, telemetry, resistance control, and reconnect still require owner hardware acceptance. Issues #3 and #4 remain open.
