# Wodra v0.1.0-alpha.32

This alpha combines the EOS session recovery, shared route elevation, and trainer command warning fixes.

- EOS authentication expiry now reauthenticates with the same rider identity and reconciles confirmed lobby membership before deciding whether to rejoin. Retries are bounded. Two-client live recovery acceptance remains pending.
- Repeated shared road sections use canonical elevations, and duplicate physical road ribbons are omitted while route navigation remains unchanged. Rendered route review remains pending.
- Gradient-command failures remain in diagnostics. The HUD warns after three consecutive failures and clears that warning after a later transport acknowledgement for the current ride. Telemetry alone does not clear it, and transport acknowledgement does not verify physical resistance.

## Verification

- Windows validation passed on the included source commit for Debug and Release.
- Local EOS-enabled Debug and Release solution builds passed.
- Trainer recovery, EOS policy, route elevation and visual-route regression checks passed.
- Live two-client EOS recovery, rendered route review, and physical trainer acceptance of the warning behavior remain outstanding. Issues #53 and #54 remain open.
