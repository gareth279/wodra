# Wodra v0.1.0

The first owner-approved Stable release of Wodra for Windows x64.

## Included

- BLE FTMS and ANT+ FE-C trainer connections, with optional heart-rate and steering devices.
- Road, Gravel, MTB and authored XC routes, riding environments, pacers and ghosts.
- Ride history and FIT recording, Strava upload integration, multiplayer, and the read-only phone companion.
- Existing rider and bicycle models.

The Stable package is rebuilt from the exact approved Alpha source commit with version `0.1.0`. Its route manifest deliberately excludes experimental Pine Hill Test content. `release-provenance.json` records the source Alpha tag, source commit, route-manifest hash, and artifact hashes.
