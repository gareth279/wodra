# Wodra v0.1.0-alpha.35

## Changes

- Added basic route-relative steering during rides using the existing Elite Sterzo Smart input or the Left/Right arrow keys.
- Arrow keys move the rider laterally while held and hold the resulting position on release. Keyboard input takes priority until a fresh intentional Sterzo input arrives.
- Added persisted steering sensitivity and Sterzo dead-zone controls. Lateral movement is smoothed and bounded to the rendered road with rider clearance; stale controller input returns the rider toward the normal line.
- Replicated rider lateral position for multiplayer visuals. Peers without the new field continue to appear on the normal riding line.
- Steering does not change route progress, elevation, distance or trainer resistance. Junction selection and free roaming are not included.
