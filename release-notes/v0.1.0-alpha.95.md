# Wodra v0.1.0-alpha.95

## Changes
- Windows FTMS trainer connection now uses bounded GATT session waits and retries for transient service-discovery failures, with connection-attempt diagnostics and clean session release.
- Auto mode can fall back from Bluetooth FTMS to ANT+ FE-C after connection setup fails. Explicit protocol choices remain selected and offer a one-time alternate connection action.
- ANT+ network-key setup is available from **Settings → ANT+ FE-C** and directly from the trainer connection screen, whether a key is configured or Bluetooth is selected.
- The ANT+ setup page can save, replace or clear the key, and independently check receiver/network initialization. ANT+ FE-C stays selectable when prerequisites are missing, with the missing key, receiver/driver and trainer requirements explained.
- Existing trainer protocol preferences remain in the per-user settings file, and the ANT+ key remains in its existing Local AppData file outside the versioned application payload.

## Validation
- Windows Release and Debug CI, source analysis and CodeQL checks pass.
- Regression coverage exercises the production connection screen, protocol fallback, key entry/replacement/clear and the independent receiver/network action.

## Hardware validation
- Physical ANTUSB-m, trainer telemetry, resistance control and trainer power-cycle recovery have not been validated by this build process. Owner hardware acceptance remains outstanding.
