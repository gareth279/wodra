# Wodra 0.1.0-alpha.40

## Changes

- Use artwork-agnostic **token/tokens** wording in the Game features helper, score HUD, pickup feedback and ride summary. Blue/gold cat artwork, scoring, saved results and challenge identities are unchanged.
- Redact Windows user-profile paths from plain logs and structured JSONL values, including slash variants, case differences, spaces, Unicode names and JSON-escaped paths. Structured output remains valid JSONL and original logs are not modified.
- Reserve diagnostic ZIP capacity for build information, sanitized settings, the current Wodra session log and the current Godot log. Oversized current logs contribute bounded tails; remaining space goes to recent sessions newest first, with truncation, missing and unreadable inputs recorded in the manifest.

## Verification

- Debug and Release solution builds and all 10 Windows regression suites passed.
- Focused tests cover token wording, path/credential redaction, JSONL validity, bounded current log tails, recent-log ordering, active writers, locked and missing logs, archive limits and ZIP contents.
- Godot 4.6.2 headless startup passed. Owner inspection of a new diagnostic ZIP remains pending.
