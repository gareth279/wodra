# Wodra 0.1.0-alpha.86

## Improved

- Improve the rider's pedalling cycle with more consistent knee trajectories and anatomical leg proportions while preserving the seated road-cycling posture.
- Align both shoes with their moving pedals. The forefoot remains supported, the soles follow the pedal platforms, and the toes point along bicycle-forward through the crank cycle.
- Keep the supplied vented helmet as a rigid assembly attached to the existing head bone, with its accepted forward orientation and fitted straps.
- Preserve the accepted sculpted hands, clothing, bicycle materials, and rider appearance while updating the rider asset and runtime attachment.

## Validation

- Windows Debug and Release builds, static analysis, CodeQL, and rider regression checks passed in CI for the release source.
- Godot 4.6.2 production RideScreen review covered the Dunedin One-way: Oval to Gardens Loop at 85 rpm, eight crank phases, and a real-time motion clip.
- The release package is built and verified by the existing Windows alpha release process.
