# Wodra 0.1.0-alpha.79

## Fixed

- Correct the 250 m velodrome to run anticlockwise, with both bends turning left and the infield, banking, apron and track lines placed relative to the actual route winding.
- Preserve the 250 m lap, zero route grade and elevation, smooth bank transitions, rider lean and wheel contact.

## Improved

- Add privacy-safe companion connection diagnostics and clearer states for setup, unavailable servers, protocol errors, pairing and ride publishing.
- Keep a successful companion recovery visible while polling trusted devices; add PHP relay checks on PHP 8.2 and PHP 8.5.

## Validation

- Windows Debug and Release builds, route regression suites, and production RideScreen review passed. Visual review covered both corners, both straights, bank transitions, lap wrap and 1280×720, 1920×1080 and 2560×1440 captures.
- PHP syntax/API suites passed on PHP 8.2 and PHP 8.5; companion browser, Wake Lock and desktop ride-trace regressions passed.
- Issue #66 remains open for real-world riding acceptance.

## Companion website deployment

- The companion website bundle is a separate deployment from the Windows installer. The updated public-only bundle and SHA-256 are provided separately; no production website files are included in this Windows release.
- Persistent iPhone pairing, browser cookie persistence and phone-side revocation still require owner-device acceptance.
