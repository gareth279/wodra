# Wodra v0.1.0-alpha.91

## Changes

- Improved the bib-short rear contour using a Blender-authored mesh.
- No changes to the helmet, jersey, pedalling animation or rider skeleton.

## Known issues

- The jersey collar remains unfinished and is tracked in [issue #173](https://github.com/gareth279/wodra/issues/173).
- The helmet revisit is tracked in [issue #175](https://github.com/gareth279/wodra/issues/175).

## Installation

The Windows installer uses a per-user installation and does not require administrator privileges. Portable Windows and Velopack packages are also provided. The Alpha update channel remains unchanged.
