# Wodra 0.1.0-alpha.78

## Improved

- Smooth the velodrome's straight-to-corner curvature and banking transitions so the track surface, rider and camera follow continuous geometry.
- Remember explicitly paired companion phones across rides and restarts, with one-time QR/manual pairing, per-phone revocation and an idle waiting state.
- Default the opt-in companion to the production Wodra website, add a safe advanced relay override, and support the standard phone Screen Wake Lock API.

## Compatibility and privacy

- Preserve the protocol 1 companion path for Alpha.77 clients while the website transitions to protocol 2.
- Remembered-phone pairing requires the companion website update; the deployable site bundle and steps are provided separately.
- Keep ride sharing opt-in and read-only; store persistent phone credentials as server-side hashes and protected browser cookies.

## Validation

- Windows Debug and Release builds, repository regression suites, PHP 8.2 API checks, companion browser-state tests, and production RideScreen scenes against an isolated local PHP relay passed.
- Issue #66 remains open for real-world riding acceptance.
