# Wodra alpha.25

This release corrects the ANT+ FE-C page request used to ask a trainer for its capability page. The request now uses the profile-defined wildcard addressing and descriptor fields and asks for one response. Capability responses are validated before Wodra marks FE-C ready, and late callbacks from an earlier connection attempt are ignored.

The reference audit compares Wodra with the pinned Incyclist implementation and records what the supplied Alpha.24 logs prove. Regression coverage checks exact page request bytes, delayed and malformed capability responses, attempt/channel filtering, and readiness requirements.

The owner has not yet retested the Flux 2 with this build. Physical trainer identification, capability-page receipt, resistance control, and recovery remain pending. #3 and #4 remain open.
