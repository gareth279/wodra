# Wodra v0.1.0-alpha.17

## Changes

- Added a per-user trainer protocol preference: Auto, Bluetooth FTMS, or ANT+ FE-C. Existing settings keep Bluetooth FTMS until the rider chooses another option.
- Added Windows ANTUSB-m support with FE-C trainer discovery, a picker when multiple trainers are nearby, live trainer identity/capabilities/telemetry, route simulation control, and reconnect handling.
- Bluetooth FTMS, ride recording, and the existing EOS-enabled release configuration remain supported.

## ANT+ setup and verification

- ANT+ FE-C requires an Elite ANTUSB-m with the official Windows driver installed and an ANT+ network key provisioned privately on the PC. The key is not included in this installer.
- Windows CI builds and regression suites pass. The ANTUSB-m SDK open/release smoke test passed on the development host.
- Flux 2 telemetry, resistance control, and reconnect behavior still need owner testing. Issues #3 and #4 remain open pending hardware acceptance.
