# Wodra v0.1.0-alpha.53

This alpha refines ambient car interactions. Vehicles now use a stable, deterministic order when predicting crossing traffic: later-spawned cars yield to earlier cars instead of both cars braking to a standstill at the same junction. Overtake state now remains active through the complete lateral return, so a car does not stay in the passing lane after clearing its target. Immediate swept-envelope checks remain in place before each movement step.

Validation includes deterministic junction, stopped-car, pedestrian, curved-overtake, and low-frame-rate regressions. Controlled close interactions in the production Dunedin Rolling City RideScreen with four AI riders and on Dunedin Oval Gardens confirmed pass and return behavior. The rendered Rolling City run measured 1.268 m minimum vehicle-to-rider model-envelope clearance; Debug and Release builds and existing rider regressions are run in CI.

Issue #28 remains open for owner physical acceptance. No cyclist simulation, cyclist separation, steering, camera, trainer, or recording code is changed by this release.
