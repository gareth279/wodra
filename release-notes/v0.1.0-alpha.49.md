# Wodra v0.1.0-alpha.49

This release contains two focused camera-framing corrections:

- Camera framing now ignores transient HUD overlays, so camera-view labels and temporary messages no longer shift the usable viewport.
- Rider and bicycle fitting uses a cached root-local envelope, avoiding frame-to-frame framing changes caused by animated world-space bounds.

Ride rendering jitter remains subject to physical acceptance testing on the owner's Windows ride setup. This release does not claim that issue #93 is resolved; please report the result with a new recording and diagnostics if jitter persists.
