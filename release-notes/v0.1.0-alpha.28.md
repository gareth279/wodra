# Wodra v0.1.0-alpha.28

- ANT+ initial connection now tries the remembered FE-C source and automatically falls back to fresh discovery if that source does not produce telemetry.
- Fresh discovery uses the SDK RX scan path to collect identified FE-C sources, filters other device profiles, and offers an explicit choice when multiple eligible sources are observed. It falls back to the normal wildcard receive path when scan mode cannot provide an eligible source.
- **Find another trainer** clears the remembered ANT identity and scans again. In-ride recovery remains pinned to the already selected source.
- Saved ANT identity is retained only when it came from fresh discovery, extended source information, or a matching channel-ID response; an unverified configured target is not persisted as resolved identity.
- Bluetooth FTMS, accepted FE-C compatibility/control behavior, telemetry freshness, ride/FIT recording, and power-cycle recovery remain in place.
