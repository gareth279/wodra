# Wodra v0.1.0-alpha.92

## Changes

- Adds **Pine Hill Test**, a 1.68 km experimental point-to-point route reconstructed from owner-supplied road footage, OpenStreetMap and Otago LiDAR data.
- Includes the reconstructed give-way intersection, corrected give-way sign lettering, roadside scenery, vegetation and buildings.
- The experimental route is explicitly labelled experimental and is included in the Windows Alpha.92 package. The six standard built-in routes are unchanged in source.
- Route assets are packaged with attribution and integrity-checked sidecars. Original footage, unredacted frames and raw route recordings are not distributed.

## Validation

- Windows Debug and Release builds, CodeQL and language analysis passed for the implementation and documentation head of PR #176.
- Offline exported application startup and route catalogue preview passed. The production RideScreen harness completed 28 route/camera/ride assertions.
- Package integrity and route asset hashes passed. A harness FIT recording passed integrity/decode checks.

## Known limitations

- **Experimental route**: geometry, road markings, sign placement and scenery are approximations, not survey-accurate navigation data.
- The review workstation could not perform normal EOS-backed online startup or an end-to-end packaged-app dummy-trainer ride, although offline startup and the production-scene ride harness passed. The publisher's own release smoke test remains required.
- The latest local Quadro P620 result was 39.0 median FPS and 28.05 ms P95. The 212.9 MiB Godot renderer video-memory counter is not a whole-card VRAM measurement.
- Existing jersey collar and helmet fit improvements remain tracked in [#173](https://github.com/gareth279/wodra/issues/173) and [#175](https://github.com/gareth279/wodra/issues/175).

## Installation

Windows per-user installer (no administrator privileges), portable ZIP and Velopack Alpha update packages are provided by the established release publisher. The Alpha update channel is unchanged.
