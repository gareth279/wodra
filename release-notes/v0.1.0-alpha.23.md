# Wodra v0.1.0-alpha.23

- ANT+ FE-C discovery now uses a wildcard slave receive channel with pairing disabled, matching the successful ANTware setup captured from the cycling PC.
- Discovery reads the trainer identity from the ANT channel-ID response and accepts ordinary ANT broadcast frames through the SDK channel callback.
- Bounded diagnostics report the effective non-secret channel settings, received message IDs, frame counts, and rejected pages without recording radio payloads or network-key bytes.
- ANT+ Setup now lives on Connect Trainer when ANT+ is selected or its key needs configuration. The visible field accepts the compact 64-bit key and Garmin's byte-list formats; the existing per-account configuration remains unchanged through updates.
- Bluetooth FTMS behavior is preserved.

The supplied ANTware capture contains 112 ordinary FE-C broadcast packets and identifies trainer 4206/17/5. That confirms the dongle and trainer transmit correctly under the captured normal receive setup. Wodra's updated discovery path has parser and configuration regression coverage, but live Wodra connection, telemetry, resistance control, and reconnect recovery still need owner acceptance on the Flux 2. Issues #3 and #4 remain open.
