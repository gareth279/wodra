# Wodra v0.1.0-alpha.18

## Changes

- ANT+ FE-C now initializes from private release runtime configuration. Riders no longer need an adopter account, SDK download, key file, PowerShell helper, or manual key entry.
- ANT+ network-key material is supplied only to the private packaging environment and is not stored in public source or build logs.
- Bluetooth FTMS, trainer protocol preference, EOS, Strava, rider data, and recording remain supported.

## ANT+ setup and verification

- Windows still requires the official Elite ANTUSB-m USB driver. Wodra does not install or replace the driver.
- Windows CI and regression checks pass. Flux 2 discovery, telemetry, resistance control, and reconnect behavior remain pending owner hardware testing. Issues #3 and #4 remain open.
