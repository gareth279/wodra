# Wodra v0.1.0-alpha.27

- ANT+ FE-C wildcard discovery now remains open for a bounded 20-second search, reports elapsed progress, and keeps scanning to identify multiple nearby trainers accurately.
- Direct searches for the remembered trainer report progress and preserve the selected identity.
