# Wodra 0.1.0-alpha.39

## Changes

- Add a per-profile **Game features** toggle to the pre-ride route picker and Settings. It defaults off; when enabled, riders can steer to collect blue cats for 1 point and rarer gold cats for 5 points.
- Use deterministic route-relative pickup layouts and swept lateral hit detection. Each rider has independent pickups and score. Attempts record route identity, challenge version, score, completion and practice eligibility separately from cycling telemetry.
- Show score, keyboard steering help when no controller is connected, brief pickup feedback and a challenge summary when enabled. A mid-ride toggle makes the challenge result incomplete and ineligible for a personal best.
- Add **Export diagnostics** to the trainer diagnostics screen and Settings. It creates a bounded local ZIP with sanitized logs, an allowlisted settings snapshot, version and runtime context, then opens the output folder.
- Keep both original cat PNGs and the approved golden application branding.

## Verification

- Debug and Release solution builds passed with EOS disabled. The full Release regression matrix passed; focused collectible placement, hit detection, attempt eligibility, log redaction and ZIP tests passed.
- Godot 4.6.2 headless import and isolated startup passed. Visual pickup inspection, physical keyboard/Sterzo collection and trainer acceptance still need owner testing.
- Local flags are diagnostic eligibility signals and do not provide cheat-proof validation. Online leaderboards and uploads are not included.
